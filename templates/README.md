# Z-Box Device Templates

Custom device parameter templates for the Zooz Z-Box hub.

## Available templates

- [Eaton RFTR9605-T](Eaton-RFTR9605-T-ZBox-template.json) — Settings for delayed OFF, panic mode, power restoration, and LED brightness. Not yet tested on a physical Z-Box hub.

## Installation

In the Z-Box web interface, open **Settings → Devices → your device → Parameters → Upload Template**.

Save the existing template first, if available. Select the JSON file and confirm the override.
